## 💡 Кратко

**PumaVPN** — готовый **VPN‑сервис под продажу**: сайт, кабинет, биллинг и выдача доступа в одном продукте.

Пользовательский путь: **сайт → регистрация → тариф → подключение**.

Сайт живой: **[pumavpn.net](https://pumavpn.net)** — интерфейс смотри там.

---

## ✅ Что внутри продукта

- Продающий лендинг и тарифная сетка
- Регистрация / логин (email + код), личный кабинет
- Биллинг: тарифы, промо, пополнение, история платежей
- Воронка подключения: устройство → клиент → активация (телефон, ПК, TV)
- Управление слотами устройств, статус подписки, отмена автопродления
- Чат поддержки и внутренняя админка (пользователи, контент, здоровье VPN)
- Блог и юридические страницы (оферта / privacy)
- Связка сайта с VPN‑инфраструктурой: выдача подписки, локации, клиентские профили

## 🧰 Стек

### Сайт и кабинет

| Слой | Технологии |
|------|------------|
| Язык | **TypeScript** |
| UI | **React 19**, **Next.js 16** (App Router) |
| Стили | CSS design tokens, light / dark theme |
| Шрифты | Inter, Unbounded (self‑host) |
| Иконки | lucide-react |
| Markdown / блог | react-markdown, remark-gfm, rehype-sanitize |
| QR | qrcode, jsQR |
| Картинки | sharp |

### Backend сайта

| Слой | Технологии |
|------|------------|
| API | Next.js Route Handlers |
| БД | **PostgreSQL** (`pg`) |
| Auth | cookie‑сессии, **bcryptjs**, одноразовые коды |
| Почта | **Resend** |
| Crypto helpers | libsodium-wrappers |
| Тесты | **Vitest**, Testing Library, jsdom |

### VPN‑слой и эксплуатация

| Слой | Технологии |
|------|------------|
| Панель / ноды | интеграция с Xray‑стеком и панелью управления (3x‑ui / multi‑node) |
| Клиентская выдача | subscription URL / JSON под популярные клиенты (Happ, INCY, v2rayTun и др.) |
| Протоколы (публично на сайте) | WireGuard + XRAY‑семейство под разные сети |
| Деплой | Linux VPS, **nginx**, **systemd**, SSL (Let's Encrypt) |
| DNS / домены | продакшен‑домен продукта, зеркала по необходимости |
